# Changelog

Все заметные изменения проекта фиксируются здесь понятным человеческим языком.

Формат версий:

- `major` — редкие ломающие изменения;
- `minor` — новые функции;
- `patch` — исправления и аккуратные улучшения.

## [Unreleased]

- Правила коммитов, версий и релизного процесса зафиксированы в проекте.

## [1.7.6] - 2026-08-29

- GitHub Pages переведён на стабильные имена клиентских файлов, чтобы кэш HTML не ломал загрузку приложения.
- Убрана зависимость Pages от случайных хешей в имени основного `js`-файла.

## [1.7.5] - 2026-08-29

- Починен деплой GitHub Pages: публикация теперь не смешивает HTML и JS из разных сборок.
- Для Pages используется стабильная временная папка публикации, чтобы не плодить дубли worktree.

## [1.7.4] - 2026-08-29

- Исправлена публикация GitHub Pages через ветку `gh-pages`.
- Добавлена безопасная нормализация старых облачных данных из Firebase.
- Закреплена схема веток `feature/* -> dev -> main -> gh-pages`.

## [1.7.3]

- Добавлены тёмная тема и обновлённый бренд `Hab-Hob`.

## [1.7.2]

- Стабильная рабочая версия GitHub Pages до исправления публикационного контура.
